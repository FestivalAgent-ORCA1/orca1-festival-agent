## 공용 브랜치 반영과 이번 보완

- `develop`의 `ca52635`까지 새 API·DB·워크플로 문서와 `.gitignore`를 개인 브랜치에 충돌 없이 반영했습니다.
- 최신 API 초안의 축제·찜·추천·주변 장소 주소와 snake_case 필드를 대조했습니다.
