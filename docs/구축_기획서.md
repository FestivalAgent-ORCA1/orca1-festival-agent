#### **서비스 핵심 기능**

1. 사용자 조건(연령대, 선호 지역, 관심사, 찜 목록) 기반 축제 추천 
    - 가입 시 설문조사 실행
    - 조건 선택 (설문조사) → 후보 축제 찾기 → 점수 계산 → AI가 추천 이유 작성
2. 방문일 기반 일정(타임라인) 생성 + 주변 관광지·맛집·카페 추천 
    - 사용자가 요청하면 실행
    - 축제 정보 확인 → 주변 장소 찾기 → 이동 시간 계산 → 시간표 배치 → 시간표 검사
3. 찜 기반 알림 
    - 매일 오전 자동 실행
    - 찜한 축제 날짜 확인 → 비슷한 축제 찾기 → 알림
4. 커뮤니티

#### **사용 데이터**

한국관광공사 TourAPI (searchFestival2, detailCommon2, detailIntro2, locationBasedList2, areaBasedSyncList2 등)

#### **직접 만들 tool**

- **외부에서 데이터 가져오는 tool**
    
    
    | Tool 이름 | 하는 일 | 안에서 연결하는 외부 서비스 |
    | --- | --- | --- |
    | `search_festivals` | 기간·지역으로 축제 목록 찾기 | TourAPI `searchFestival2` (DB 저장 후에는 우리 DB 조회로 변경) |
    | `get_festival_detail` | 축제 1개의 위치, 운영 시간, 요금, 소개 | TourAPI `detailCommon2`, `detailIntro2` |

    | `calc_travel_time` | 장소 사이 실제 이동 시간·거리 계산 (자동차 기준) | 카카오모빌리티 자동차 길찾기 API |

#### **외부 서비스 tool**

| 서비스 | 제공처 | 어디서 쓰나 | 역할 | 담당 |

| **TourAPI** | 한국관광공사 (공공데이터포털) | 백엔드 `tools/`, `batch/` | 축제·관광지·음식점 데이터 | BE1 |

| **카카오모빌리티 자동차 길찾기 API** | 카카오모빌리티 | 백엔드 `calc_travel_time` 안 | 두 장소 사이 실제 도로 기준 이동 시간·거리 | BE1 |

**카카오모빌리티 길찾기 사용 시 알아둘 것**

- **자동차 길찾기만** 무료로 쓸 수 있음. 무료 사용량(하루 약 1만 건) 안에서는 별도 제휴 없이 사용 가능.
- 도보 길찾기는 유료 제휴로만 제공되고, 대중교통은 카카오모빌리티에서 제공 안 함.
- 카카오 개발자 사이트에서 앱을 만들고 **REST API 키**를 발급받아 백엔드 `.env`의 `KAKAO_REST_API_KEY`에 넣습니다. (지도용 JavaScript 키와 다른 키. 같은 카카오 앱에서 둘 다 발급 가능.)
- 사용 권한 신청이 필요하다는 안내가 나오면 카카오 데브톡에 신청. 최대한 미리 신청하기.
- 장소 10곳의 모든 조합을 계산하면 일정 1개에 90번을 호출함. 호출 수를 줄이려면 `build_timeline`이 정한 방문 순서대로 이웃한 두 장소 사이만 계산하고, 한 번 계산한 두 장소 사이 시간은 DB에 저장해서 다시 쓰는 방식으로.
</aside>
