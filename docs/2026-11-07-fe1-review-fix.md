# 2026-11-07 · FE1 추천 영역 리뷰 반영

대상: [PR #1의 BE1 리뷰](https://github.com/FestivalAgent-ORCA1/orca1-festival-agent/pull/1#pullrequestreview-5798724429).

## 수정한 동작

- 추천 API가 `400 ONBOARDING_REQUIRED`를 반환하면 추천 제목·오류 안내·재시도 버튼을 포함한 추천 영역만 숨깁니다. 일반 축제 목록과 검색은 계속 표시합니다.
- 관심사 설정 화면은 FE3의 연결 범위이므로, 아직 없는 `/onboarding`으로 이동시키는 버튼은 추가하지 않았습니다. 리뷰에서 제안한 두 방식 중 추천 영역 숨김을 적용했습니다.
- API 모드의 로그인 상태일 때만 추천 영역을 표시합니다. 세션이 사라지면 이전 추천 상태를 표시하지 않습니다.
- 다른 400·500·네트워크·시간 초과 오류는 기존 오류 안내와 재시도를 유지합니다.

## 검증

실제 팀 계정이나 서버를 사용하지 않는 로컬 API 검증 환경에서 브라우저로 확인했습니다.

| 응답·상태 | 확인 결과 |
| --- | --- |
| 로그인 상태 + `400 ONBOARDING_REQUIRED` | 추천 제목·오류·재시도 숨김, 일반 축제 목록 유지 |
| 로그인 상태 + `400 BAD_REQUEST` | 추천 오류 안내와 재시도 유지 |
| 로그인 상태 + `500 INTERNAL_ERROR` | 추천 오류 안내와 재시도 유지 |
| 500 오류 뒤 서버 정상화 후 재시도 | 추천 카드·추천 이유 표시, 오류 안내 제거 |
| 비로그인 상태 | 추천 영역 숨김, 추천 API 요청 없음, 일반 축제 목록 유지 |

- 기존 자동 테스트 17개 통과.
- `pnpm build` 성공.
- 실제 팀 서버·로그인과의 통합 검증 및 팀원 승인은 후속 단계입니다.
