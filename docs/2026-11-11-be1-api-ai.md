## 알게 된 것 (팀 공유)

- **TourAPI 축제 응답은 `areacode`가 항상 비어 있음** → 법정동 코드(`lDongRegnCd`)로 지역을 정함. 변환표는 [tags.md](tags.md) 2장
- **법정동 코드 `12` = 전남광주통합특별시**. 시·군·구 코드로 광주(`5`)와 전남(`38`)을 나눔
- 카페 분류 코드 확정: cat3 `A05020900` = lclsSystm2 `FD05` ([tags.md](tags.md) 4장)
- **관광지 데이터가 적음**: 해운대 반경 3km 관광지 3개, 일부 축제는 주변 관광지·카페 0개 → 이때도 일정은 축제·식당 위주로 만들어짐
- **Groq 무료 플랜은 모델마다 분당 8,000토큰** → AI 채팅은 분당 2번 정도가 한계. 시연 때 여러 명이 동시에 쓰면 502 `EXTERNAL_API_ERROR`가 날 수 있음
- gpt-oss 모델에 "JSON으로 답해"라고 하면 없는 `json` Tool을 불러 Groq가 400 오류를 냄 → 최종 답변을 `final_answer` Tool로 받도록 바꿈 ([workflow.md](workflow.md))
- **Aiven MySQL 무료 플랜이 2026-12-21에 종료 예정** (Aiven 화면 안내) → 이후 DB를 어떻게 할지 팀 결정 필요
