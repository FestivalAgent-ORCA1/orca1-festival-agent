# 관심사 태그 · 지역 · 연령대 목록

> 담당: BE1 · 상태: **초안** (확정 전까지 코드 값을 바꿀 수 있음. 확정 후에는 값 변경 시 팀 공지 필수)

이 문서의 **코드 값**은 DB, API, 프론트, AI 지시문에서 모두 그대로 쓰입니다.
화면에는 `이름`을 보여주고, 저장·전송은 항상 `코드`로 합니다.

| 코드 | 이름 | 이런 축제에 붙임 |
| --- | --- | --- |

| `tradition` | 전통·역사 | 민속놀이, 전통문화 재현, 역사 인물·사건 기념 |
| `food` | 음식·먹거리 | 먹거리 장터, 향토 음식, 푸드트럭 |
| `drink` | 술·음료 | 맥주, 와인, 전통주, 커피·차 |
| `nature` | 꽃·자연 | 꽃 축제, 단풍, 갯벌, 숲, 생태 |
| `night` | 빛·야경 | 불꽃놀이, 등 축제, 미디어아트 야간 행사 |
| `experience` | 체험 | 만들기, 수확 체험, 참여형 프로그램 |
| `family` | 가족·어린이 | 어린이 대상 프로그램, 가족 단위 행사 |

| `local` | 특산물·장터 | 지역 농수산물, 특산품 판매 |
| `sports` | 스포츠·레저 | 마라톤, 물놀이, 자전거, 수상 레저 |
| `winter` | 겨울·눈·얼음 | 눈꽃, 얼음 낚시, 썰매 |

### 사용 규칙

- **사용자**: 첫 설정(온보딩)에서 **1~5개** 선택. 내 정보 페이지에서 수정 가능.
- **축제**: `batch/extract_tags.py`가 축제 소개글(overview)을 읽고 AI로 **1~3개** 붙임.
  AI가 위 목록에 없는 코드를 돌려주면 버림.
- 태그를 추가·삭제할 때는 이 문서 → `GET /api/meta/tags` 응답 → 기존 축제 태그 재추출 순서로 진행.

## 2. 지역 (시·도)

| 코드 | 이름 | 코드 | 이름 |
| --- | --- | --- | --- |
| `1` | 서울 | `31` | 경기 |
| `2` | 인천 | `32` | 강원 |
| `3` | 대전 | `33` | 충북 |
| `4` | 대구 | `34` | 충남 |
| `5` | 광주 | `35` | 경북 |
| `6` | 부산 | `36` | 경남 |
| `7` | 울산 | `37` | 전북 |
| `8` | 세종 | `38` | 전남 |
| - | - | `39` | 제주 |

- TourAPI `areaCode` 값과 같음. 숫자처럼 보여도 **문자열**로 다룸 (`"31"`).
- ⚠️ TourAPI v2(KorService2)는 법정동 코드(`lDongRegnCd`)도 함께 제공함. BE1이 실제 응답을 확인한 뒤,
  `areaCode`가 비어 있는 데이터가 있으면 법정동 코드 → 위 코드로 변환하는 표를 이 문서에 추가.
- 사용자: 선호 지역 **0~3개** 선택 (0개 = 전국).
- 시·군·구 단위는 1차 범위에서 제외 (필요하면 추가).
